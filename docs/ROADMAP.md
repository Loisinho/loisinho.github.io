# Implementation Roadmap

## Phase 0 — Repository Foundation

- Create a Vue 3 + TypeScript + Vite project.
- Configure ESLint, Prettier, Tailwind and scripts.
- Add a minimal structure and documentation.
- Set up CI for lint, typecheck, tests and build.

## Phase 1 — Application Framework

- Configure Vue Router with the initial routes.
- Configure Vue I18n.
- Implement the layout, navigation and footer.
- Implement light/dark theme support with persistence.
- Define visual tokens, typography and breakpoints.

## Phase 2 — Content

- Define `Profile`, `Skill`, `Experience` and `Project` models.
- Implement bilingual local data.
- Define a `ContentService` and a local data provider.
- Connect views to services rather than direct data files.

## Phase 3 — Views

- Home.
- About.
- Experience.
- Skills.
- Projects and project details.
- Contact.
- 404 Page.

## Phase 4 — Quality and Deployment

- Unit and component testing.
- E2E testing for navigation, languages and themes.
- SEO, accessibility, performance and image optimization.
- Deployment and verification of SPA routes.

## Phase 5 — Optional Evolution

- Privacy-focused analytics.
- Additional languages ​​or features.
